# Regelwerk

## Website veröffentlichen
1. Entpacke dieses Archiv.
2. Lade **index.html**, **app.js**, **styles.css**, **README.md** und **.nojekyll** gemeinsam in den Veröffentlichungsordner deines GitHub-Pages-Repositories.
3. Öffne die veröffentlichte Seite und melde dich im Admin-Modus an, um Dokumentseiten und Abschnitte zu bearbeiten.

## Funktionen
- Mehrere Dokumentseiten und Kapitel, lokale Speicherung im Browser
- Formatierbarer Text mit Schriftart/-größe/-farbe, Textmarker, Tabellen, Listen, Zitaten, Links, Code-Blöcken und eingebetteten Bildern
- Lokale ZIP- und HTML-Exporte
- Responsive Bedienoberfläche und optionale Oberflächenklänge

## Hinweis zur Speicherung
Seitenänderungen werden lokal im Browser gespeichert. Wenn du in einem anderen Browser arbeitest oder Site-Dateien neu veröffentlichst, exportiere vorher ein ZIP, damit die aktuellen Inhalte darin eingebettet sind. Ein statisches GitHub-Pages-Projekt synchronisiert keine Bearbeitungen zwischen verschiedenen Besuchern.
